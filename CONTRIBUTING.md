# Contributing to Malware Classification System

Thank you for your interest in contributing!

## Development Workflow
- Fork the repository and clone your fork.
- Create a new branch for each feature or bugfix (`feature/your-feature`, `bugfix/your-bug`).
- Write clear, concise commit messages.
- Ensure all tests and linters pass before submitting a PR.
- Open a pull request to the `main` or `develop` branch.

## Branching Strategy
- `main`: Production-ready code.
- `develop`: Latest development changes.
- `feature/*`: New features.
- `bugfix/*`: Bug fixes.

## Commit Guidelines
- Use descriptive commit messages (e.g., `fix: correct API endpoint`, `feat: add user authentication`).
- Reference issues where applicable.

## Code Style
- Python: Follow PEP8, use Black and Flake8.
- JavaScript/React: Use Prettier and ESLint.

## Testing
- Add/maintain unit and integration tests for new features.
- Run all tests before submitting a PR.

## Issues
- Use GitHub Issues for bugs, features, and questions.

Thank you for helping improve this project!
